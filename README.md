# Nginx como Proxy Reverso com Node.js

Projeto do desafio Full Cycle com Nginx, Node.js e MySQL orquestrados pelo Docker Compose.

## Executar

Na raiz do projeto, execute:

```sh
docker compose up
```

A aplicação estará disponível em http://localhost:8080. Cada acesso insere um nome na tabela `people` e exibe os nomes cadastrados.
